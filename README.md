## 📌 About The Project

This project was built focusing on learning **Tailwind CSS**, applying modern and responsive styling over a semantic HTML structure.

It was originally created during my technical course as a practical assignment requested by the teacher to reinforce fundamental concepts of **pure HTML5 and CSS3**.

After completing the course and starting my studies in new technologies for the web development market, I took a course focused on **Tailwind CSS**. As a **practical self-assessment**, I decided to refactor and style this application from scratch using the framework, testing my skills in responsive layout, utility classes, and modern design.

---

## 🚀 Technologies Used

- **HTML5** (Semantic)
- **Tailwind CSS v4** (Utility-first CSS framework)
- **Git & GitHub** (Version control)

---

## 💡 Key Learnings & Features

During the rebuilding process with Tailwind CSS, I applied the following concepts:

- **Mobile-First Responsiveness:** Utilizing breakpoints (`sm:`, `md:`, `lg:`, `xl:`, `2xl:`) to adapt the layout seamlessly from mobile devices to ultra-wide monitors.
- **Flexbox & Layout Alignment:** Building dynamic headers, hero sections, countdown timers, and footers using `flex`, `flex-col`, `items-center`, and `justify-between`.
- **Component Styling:** Interactive buttons with hover states (`hover:opacity-70`), smooth transitions (`duration-300`), and rounded borders.
- **Color Palettes & Opacity:** Applying a Christmas-themed color palette with opacity control.

## 🛠️ How to Run Locally

1. **Clone this repository:**
   ```bash

   ```

2. **Navigate to the project folder:**
   ```bash
   cd YOUR_REPOSITORY

3. **Install dependencies (if using Tailwind CLI):**
   ```bash
   npm install

4. **Run the Tailwind compiler in watch mode:**
   ```bash
   npx @tailwindcss/cli -i ./src/css/input.css -o ./src/css/tailwind.css --watch

5. **Open index.html in your browser.**

## 📌 Sobre o Projeto

Este projeto foi desenvolvido com foco no aprendizado de **Tailwind CSS**, aplicando estilização moderna e responsiva sobre uma estrutura HTML semântica.

Ele foi criado originalmente durante o meu período de curso técnico como uma atividade prática proposta pela professora para fixar os conceitos fundamentais de **HTML5 e CSS3 puros**.

Após a conclusão do curso e dando início aos meus estudos em novas tecnologias para o mercado de desenvolvimento web, realizei um curso focado em **Tailwind CSS**. Como forma de **autoavaliação prática**, decidi refatorar e estilizar essa aplicação do zero utilizando o framework, testando meus conhecimentos em layout responsivo, utility classes e design moderno.

- **HTML5** (Semântico)
- **Tailwind CSS v4** (Framework CSS utility-first)

## 💡 Aprendizados e Recursos Utilizados

Durante o processo de reconstrução do projeto com o Tailwind CSS, apliquei os seguintes conceitos:

- **Responsividade Mobile-First:** Uso de breakpoints (`sm:`, `md:`, `lg:`, `xl:`, `2xl:`) para adaptar o layout perfeitamente de celulares a monitores ultra-wide.
- **Flexbox & Alinhamento de Layout:** Construção de cabeçalhos, seções principais, contadores regressivos e rodapés dinâmicos usando `flex`, `flex-col`, `items-center` e `justify-between`.
- **Estilização de Componentes:** Botões interativos com estados de hover (`hover:opacity-70`), transições suaves (`duration-300`) e bordas arredondadas.
- **Paleta de Cores e Opacidade:** Aplicação de uma paleta temática de Natal com controle de opacidade.
